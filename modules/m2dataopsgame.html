🧭Regional Problem, or Just One Dealer?

Before you escalate, you need to know who to escalate to. A dip that hits several dealers in the same region, in the same month, usually points at something systemic — a dispatch or logistics change. A dip in just one dealer, with the rest of the region untouched, is a dealer-specific issue.

⚠️ Systemic (West, this dataset)

  • 3 of 5 West dealers start sliding the same month
  • The other 2 West dealers are untouched
  • → points at something regional, e.g. dispatch delays

✅ Dealer-specific (North, this dataset)

  • Jaipur Motors has one bad month, then fully recovers
  • The other 4 North dealers never move
  • → isolated to one dealer, one month

🔒Before You Uploadfull version in Session 3

Quick version now — the full indexing-and-anonymising workflow is Session 3's whole topic.

✅ Do

  • Swap real names for IDs (Dealer-07) if you're just exploring patterns
  • Strip phone, PAN, GST and other identifiers before it leaves your machine
  • Check your org's data policy on what's allowed to leave the building

❌ Don't

  • Upload a raw export "just to try it" and clean up later
  • Assume a public AI tool's privacy settings cover you
  • Wait for Session 3 to start thinking about this — start now

📚8 Ready-to-Paste Promptsyour library

🔍 Find the quiet decliners

Trend scan 
Using this dataset (dealer, region, month, units),
find every dealer whose units fell steadily over
the period with no single dramatic month. Rank by
% decline. Show the month each decline started.

🧬 Catch mix erosion

Mix-over-time check 
For each dealer, compare product-category share
(% premium vs % economy) in the first 3 months vs
the last 3 months. Flag any dealer where total
volume is flat but premium share dropped by more
than 10 points.

🧭 Regional vs dealer-specific

Root-cause split 
Group declines by region and month. Tell me which
regions have 2+ dealers declining in the same
month (likely a shared cause) versus which declines
are isolated to a single dealer. List both groups
separately.

🚦 Build the dashboard

RAG status generator 
Build a table: one row per dealer, with a status
of Green / Yellow / Red. Red = declining 3+ months
in a row. Yellow = declined then recovered within
2 months. Green = everything else. Include the
region and the reason for the status.

🔒 Anonymise before upload

Strip identifiers 
Replace every dealer name in this file with an ID
like Dealer-01, Dealer-02, keeping a separate
mapping table only I can see. Remove any phone,
email, PAN or GST columns entirely before showing
me the working data.

🧮 Verify AI's own math

Show the working 
Recalculate the total units for [region] and show
your row-by-row working, not just the final number.
Confirm how many rows you actually used and whether
that matches the full dataset.

📝 Brief a regional head

12-month summary 
Summarize 12 months of performance for [region] in
under 150 words for a regional head with 90 seconds
to read it: 1 headline, top 2 risks with dealer
names, 1 recommended action.

📋 Weekly ops brief

One-page brief 
Turn this month's raw sales data into a one-page
ops brief: 3 bullets on what changed, 1 dealer to
watch, 1 open question you couldn't answer from
this data alone. Flag anything you're unsure about.
