🧠 Part 1: Why AI Changes Operational Data Work at VEKA

▼

The Problem: The Monthly Review Nobody Has Time to Do Properly

VEKA's channel business generates the same data every month for every dealer: volume against target, product mix, dispatch performance, complaints, outstanding, audit scores. Twenty dealers over a year is 240 rows and two dozen fields. A regional manager preparing for review faces this:

📋 Manual Process

  • Open the sales sheet, the complaint log and the outstanding report
  • Build a pivot per dealer, per month
  • Eyeball 240 rows for anything unusual
  • Check who is below target — the easy part
  • Notice mix and dispatch trends — almost never happens
  • Write the commentary
  • Build the slides

⏱ Time: 3–5 hours per monthly review

🤖 With AI Analysis

  • Upload one indexed CSV
  • Paste one analysis prompt
  • AI reads all 240 rows at once, across every field
  • Flags achievement, mix, dispatch, credit and quality together
  • Finds the trends that only appear across months
  • Drafts the commentary with sources cited
  • Ask follow-ups for anything that looks odd

⏱ Time: 3–8 minutes per analysis

💡 The real gain is not speed. It is that the analysis nobody had time for — mix erosion, cross-field patterns, slow declines — gets done at all. Speed just makes it possible.

Three Levels of AI Data Analysis

📊 Descriptive

"What happened?"

  • Totals and summaries
  • Best and worst dealers
  • Trend identification

Reliable. Verify the arithmetic.

🔍 Diagnostic

"Why did it happen?"

  • Pattern and cluster detection
  • Cross-field correlation
  • Anomaly flagging

Useful for hypotheses. Not for conclusions.

🔮 Predictive

"What will happen?"

  • Trend extrapolation
  • Which dealer needs attention first
  • Where the erosion goes next

Treat as a prompt for a conversation, never a forecast.

⚠️ The level you must be careful with is diagnostic. AI is genuinely good at spotting that three things move together. It is not able to tell you which caused which — but it will happily write a sentence that sounds like it can. Ask it for candidate explanations and the evidence needed to test each, never for "the reason".

File hygiene — the five things that break an analysis

  • Merged cells. Unmerge everything. They arrive as blanks and shift your columns.
  • Multi-row headers. One header row only. Flatten "Q1 / Volume" into "Q1_Volume".
  • Units in the cell. "42 units" is text, not a number. Put the unit in the column name.
  • Blank rows and subtotal rows. Delete them. AI will treat a subtotal as a data row and double-count.
  • Mixed date formats. Pick one and stick to it. Mixed formats silently produce wrong trends.
💡 Ten minutes of file cleaning beats any prompt improvement. The most common cause of a vague, useless analysis is a messy file, not a weak prompt.

Good vs Bad Prompts for Data Analysis

❌ Bad Prompt

"Analyse this data"

Result: a generic summary of what the columns are. Misses every real pattern. Then everyone concludes AI isn't useful for data.

✓ Good Prompt

"Flag every dealer whose last 3 months average is more than 20% below their first 3 months. Rank all 20 by combined risk. For the top 3, give the fields that support it and what I should ask them. One page, for a regional review."

Result: three dealers named, evidence cited, questions ready.

Carry the Session 1 structure across: Role (regional sales manager) → Context (the file, and what the columns mean) → Task (one verb: flag, rank, compare) → Constraints (thresholds, no invented numbers, cite the rows) → Format (table, one page, dashboard).
⚠️ One data-specific constraint to add every time: "Cite the dealer and month for every figure you state, and tell me if a calculation is one you performed rather than read from the file." Without it you cannot tell a read value from a computed one — and the computed ones are where errors live.

LIVE DEMO Prompt 2: Who Is Quietly Losing Volume

▼

⏱ 3 min Highest-value prompt in the module

COPY-PASTE PROMPT
Using the uploaded dealer dataset, find erosion that a month-on-month review would not catch. 1. For every dealer, compare the average Order_Volume_Index of the FIRST 3 months against the LAST 3 months. Show the percentage change. Rank from worst to best. 2. IMPORTANT: before you interpret anything, check whether the portfolio as a whole declines over the same window. If it does, tell me the portfolio-level change first, then re-state each dealer's change RELATIVE to that. I need to know who is losing ground versus who is just moving with the season. 3. Identify the dealers whose decline is materially worse than the portfolio trend. For each: was any single month dramatic, or was it gradual? State the month-by-month figures. 4. Flag any dealer where the decline is NOT visible in Achievement_Percent because their target was also low. RULES: - Do not describe a gradual decline as a "drop" or an "event". - Cite the months. - Do not attribute a cause. Label any explanation [hypothesis].
WHAT GOOD OUTPUT LOOKS LIKE
PORTFOLIO CONTEXT FIRST Portfolio volume index, first 3 months vs last 3: a modest decline. Months 2025-10, 2025-11, 2026-02 and 2026-03 are the strongest in the file; 2026-06 to 2026-08 the weakest. This looks seasonal, so individual dealer declines must be read against it. DEALERS DECLINING FAR BEYOND THE PORTFOLIO TREND Dealer E (West) 30.4 -> 12.5 -59.0% Dealer K (North) 50.8 -> 22.2 -56.3% Dealer N (South) 41.5 -> 22.3 -46.4% These three are an order of magnitude worse than every other dealer. No single month falls off a cliff — Dealer E declines in small steps each month, which is exactly why a month-on-month review would never escalate it. Twelve small declines and a third of the volume is gone. MOVING WITH THE SEASON — not a concern on this evidence Dealer C -17.0%, Dealer J -13.4%, Dealer P -12.7%, Dealer L -9.6%, Dealer B -9.5%, Dealer M -9.4%, Dealer F -8.9%, Dealer A -8.4%, Dealer G -6.9%, Dealer D -6.6%, Dealer T -6.2%, Dealer O -5.0%, Dealer R -3.7%, Dealer S -1.7%, Dealer I -1.5% HIDDEN BY TARGET SETTING Dealer E and Dealer K both carry lower targets than their history would justify, so Achievement_Percent understates the decline. Achievement of 70.5% and 73.2% is bad — but the underlying volume loss is worse than those figures suggest. [hypothesis] All three are Tier-2. 💡 Instruction 2 is the important one. Without it, AI reports fifteen "declining" dealers and the real three get lost in the noise. Forcing it to establish the baseline first is the difference between a useful answer and an alarming, useless one.

[hypothesis] WHAT THIS DATASET CANNOT TELL YOU - Local market size and competitive intensity per dealer - Whether the dealer's own team is stable - What they actually lead with when quoting - Whether the audit score reflects investment in tooling or something else - Win/loss reasons Without at least the first and the last of these, "Metro dealers perform better" may simply mean "larger markets produce larger numbers".
💡 Instruction 4 is the habit worth building. "What would you need that this file doesn't have?" turns an analysis into a data-collection plan, and it's the fastest way to find out whether your monthly report is even measuring the right things.

📂 Part 4: Case Studies — What AI Caught, and What It Got Wrong

▼

Five findings from this dataset. Four are things a normal monthly review misses. The fifth is a mistake AI makes reliably — and it is the most important one on the page.

CASE STUDY CS-1: A Third of the Volume, Gone in Small Steps

▼

📍 What the data shows

Dealer E's volume index falls from 30.4 (first 3 months) to 12.5 (last 3). Dealer K falls 56.3%, Dealer N 46.4%. No single month shows a dramatic collapse in any of them.

💥 Why a human review missed it

Month-on-month reporting compares this month to last month. A 4–5% monthly decline never triggers anything — it reads as normal fluctuation, and there is always a plausible local reason. Twelve of those and the account is half gone. Nobody was negligent; the reporting shape simply cannot see it.

✅ What AI did differently

It compared a three-month window at each end of the year rather than adjacent months, and it did that for all 20 dealers at once. That is a trivial analysis that nobody had time to run consistently. The finding is not clever — it is just done.

CASE STUDY CS-2: North Hit Its Target While Losing Value All Year

▼

📍 What the data shows

North's premium mix falls from 30.8% to 17.1% across twelve months. Over the same period, North's volume holds — Dealer G averages 97.3% achievement, Dealer I 94.2%. The decline is spread across all five North dealers, not concentrated in one.

💥 Why a human review missed it

Because the region passed every test it was given. Volume: on target. Achievement: green. Credit: clean. Service: fine. Mix sat in a column nobody had a threshold for, so nobody had a reason to look at it.

✅ The lesson

This is the most valuable finding in the dataset and the hardest to reach manually, because it requires holding two fields together across time. It also has no answer in the file — AI correctly produced three testable hypotheses and said which data would settle them, rather than picking one.

CASE STUDY CS-3: Two Dealers Hitting Target, Damaging the Brand

▼

📍 What the data shows

Dealer Q: audit 62.3, 35 complaints, achievement 94.9%. Dealer B: audit 63.3, 26 complaints, achievement 96.8%. The two lowest audit scores in the channel, both attached to entirely respectable commercial performance.

💥 Why a human review missed it

Because commercial and quality data live in different reports, owned by different functions, reviewed in different meetings. Nobody was looking at both columns in the same row. Dealer B is a Metro account hitting 96.8% — on the sales dashboard they are a success story.

✅ Why it matters more than the revenue

A homeowner with a poorly fabricated window blames the window, not the fabricator. Volume from a dealer whose audit score sits 20 points below the channel is not straightforwardly good news. AI found this in one pass because it does not respect the boundaries between your reports.

CASE STUDY CS-4: Three Good Dealers Marked Down for Someone Else's Problem

▼

📍 What the data shows

East averages 18.5 dispatch days against 11–12 elsewhere, with on-time at 55.2%. It degrades from 16.7 to 20.0 days after month 6. Dealers R, S and T show no dealer-specific problems — their service metrics reflect the region they sit in.

💥 The trap

A dealer scorecard that includes on-time delivery will mark down every East dealer, including the three doing nothing wrong. They then arrive at their review to be told about a problem they cannot fix, which is the fastest way to lose a good dealer's goodwill.

✅ The prompt instruction that fixed it

"Separate the dealer from the region: state clearly which problems are theirs and which are the region's." Without that line, the analysis blames the dealers. With it, one conversation goes to Supply Chain and three difficult meetings never need to happen.

CAUTIONARY CS-5: When AI Got It Confidently Wrong

▼

📍 What happened

Asked simply to "find declining dealers", AI returned a list of fifteen dealers with negative trends and described the portfolio as being in broad decline. Dealer A, one of the two best accounts in the channel, appeared on the list at −8.4%.

💥 Why it was wrong

Months 10–12 in this dataset are a seasonal low and months 2–4 a seasonal high. Comparing them makes almost every dealer look negative. The analysis was arithmetically correct and completely misleading. Acting on it would have meant fifteen difficult dealer conversations, and the three that genuinely mattered buried among them.

✅ The fix — one instruction

"Before you interpret anything, check whether the portfolio as a whole declines over the same window. If it does, state the portfolio change first, then re-state each dealer relative to it." Adding that reduced fifteen names to three, correctly.

📌 The general lesson

AI will not tell you it lacks a baseline. It will produce a confident, well-formatted, internally consistent answer to the question you asked — including when the question was missing the context that made it meaningful. Always ask for the baseline before the exception. This applies to every comparison you will ever run: against what, over what period, compared to whom.

🔒 Part 5: Anonymise Before Uploading

▼
⚠️ Today's dataset is already safe. Your real one is not. The file you used in this session ships with dealers as A–T and every value indexed. Your actual channel report has dealer names, rupee values, margins and contact details. Session 3 covers the full framework — this is the two-minute working version.

Quick Anonymisation — 2 Minutes in Excel

FieldDo thisWhy it still works
Dealer / customer namesFind-and-replace with Dealer A, B, C…AI needs to know rows differ, not what they're called
Volume and valueDivide by a factor only you know, or index so the largest = 100Every ratio, trend and comparison is unchanged
Margins and discountsRemove the column entirelyAlmost never needed for the analysis you're running
Regions and citiesRegion 1–4, or keep if not identifyingKeep only if you need the geographic pattern
Contact names, phones, emailsDelete the columnsNever relevant to an analysis
Individual employee dataNever upload, in any formNo exceptions. Session 3 explains the legal position.
💡 Do it in the file, not in your head. Find-and-replace on a copy is repeatable and complete. Retyping "carefully" is how one row slips through — and one row is enough.
⚠️ Then check for re-identification. "Dealer A, West, Metro, since 2014, highest volume in the portfolio" identifies exactly one company to anyone in the industry. Removing the name is not sufficient if the remaining fields point to one dealer. Drop a field or widen a category.

🚀 Part 7: Follow-Up Patterns & Your Prompt Library

▼

6 Follow-Up Questions That Deepen Any Analysis

#Ask thisWhat it gets you
1"Compared to what? Show me the baseline before the exception."Kills the seasonality error from CS-5. Ask it first, every time.
2"Which of those figures did you calculate, and which did you read?"Isolates where an arithmetic error could be hiding
3"What in this file contradicts what you just told me?"Surfaces the counter-evidence AI skipped over
4"What would you need that this file doesn't contain?"Turns the analysis into a data-collection plan
5"Give me three explanations, and what would distinguish them."Stops a single confident cause from becoming the accepted story
6"Now write it for a dealer who is about to be told this."Reframes a finding as a conversation, not an accusation
✅ Question 3 is the most under-used prompt in this entire programme. AI builds a coherent narrative and drops the rows that don't fit. Asking directly for the contradictions gets them back.

Build Your Prompt Library

Save the prompts you actually used, with the changes you made. A prompt you tuned for your own report beats a generic one every month afterwards.

  • Name it for the task, not the tool — "Monthly channel risk scan", not "ChatGPT prompt 3"
  • Save the whole thing, including the rules section. That section is what makes it safe to reuse.
  • Note what it got wrong the first time and the instruction that fixed it. That note is worth more than the prompt.
  • Record your baseline — how long this analysis takes you manually today. Session 4 will ask for that number.
